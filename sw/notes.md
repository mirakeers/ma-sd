#### Dynamic vs Condenser mic

Dynamic mics are not too sensitive which is usually wanted. Requires a lot of gain. They are very robust in case of, humidity, sound pressure level, less linear (have a sound to them), very affordable

Condenser mics need phantom power, are more linear, very good impulse response, usually very , they have a self-noise that is usually mentioned on the box. 


Ribbon mics (type of dynamic mic), normally always **figure of 8** aka picks up sound in 1 dimension. They can sound dull. They do not handle sound pressure levels well. NO phantom power usually, as they can get damaged. Some of them do need Phantom Power. When you plug one in make sure you turn it off first.


#### Small vs large diaphragm

Bneath 2 cm: small diaphragm, more linear (more natural)
Above that: large diaphragm, less noisy, more surface area so can picks up cleaner signal,

### Stereo micing

Stereo recording: different ways to place the mics: patterns XY, AB, ORTF, MS

Configure the gain so that the loudest point is around -10dB. If the loudest point would come to 0dB, clipping will happen which can cause distortions etc. Always leave some headroom (-1dB) when sending masters off

In practice: the interface - Operational modes: Full mode vs DAW mode


Sample rate: 48kHz 7 96kHz, the higher the sample rate, the lower the latency. Matters a lot for example live audio. The higher the sample rate, the lower the channel count.

Speakers in audio studio:
KSD: input 1-2
ADAM input 3-4-5-6-7-8


Stereo bars can be used to configure stereo recording patterms

https://sengpielaudio.com/: see recording patterns, how distances between them affect the polar patterns

Each pattern has its own advantages, no holy grail

AB: Good room impression, but not so good, no mono compatibility, uses time delay instead of itensity
XY: Both mics are in the same place, but point in different direction. Uses itensity to decide which signal comes in first


The wall behind mics can reflect sound !
